# 🚀 Build • Break • Learn

Welcome to **Build • Break • Learn**!

This repository is my personal engineering lab where I explore **Databricks**, **Apache Spark**, **AI**, **Machine Learning**, and **Data Engineering** by building real projects, running experiments, and documenting what I learn along the way.

I believe the best way to learn a technology is not just by reading documentation, but by **building something, breaking it, understanding why it broke, and then building it better.**

---

# 🎯 Repository Goal

The purpose of this repository is to:

- Learn by building real-world projects
- Understand how technologies work internally
- Benchmark and analyze performance
- Share practical examples with the engineering community
- Document lessons learned throughout the journey

Whether you're a beginner or an experienced engineer, I hope these experiments help you understand the concepts a little better.

# 💡 Learning Philosophy

Technology evolves quickly.

Instead of memorizing APIs or syntax, I focus on understanding the fundamentals.

Every experiment follows the same approach:

1. Learn the concept
2. Build it
3. Break it
4. Measure it
5. Understand why it behaves that way
6. Share the findings

That's the idea behind **Build • Break • Learn**.
